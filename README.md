A fast, read-only make.fun frontend in plain static files: the live bounty board with live pots, entry fees and time left; bounty pages with rewards tables; leaderboards; and public profiles — no framework, ETag-cached API reads, and a first load of a few kilobytes.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
